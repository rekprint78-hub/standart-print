# StandART — Печать (лендинг)

Одностраничный сайт производственной компании StandART: **широкоформатная, интерьерная и УФ-печать**.
Один экран без прокрутки на десктопе (три карточки услуг), на телефоне — обычная вертикальная вёрстка.
Тёмная тема, красный акцент, Montserrat. Один файл, без сборки.

- `index.html` — весь сайт (HTML + CSS + JS в одном файле)
- `assets/og.png` — картинка для превью ссылки в мессенджерах (1200×630)

## Как поменять контакты
Открыть `index.html`, найти в самом низу в `<script>` блок:

```js
const CONTACT = {
  phoneText: "+7 (000) 000-00-00",
  phone:     "+70000000000",
  whatsapp:  "70000000000",
  telegram:  "stand_artproduction",
  email:     "info@standart-production.ru"
};
```

Править **только здесь** — телефон, WhatsApp, Telegram и e-mail подставятся по всему сайту
(шапка, нижняя полоса, модальное окно расчёта).
