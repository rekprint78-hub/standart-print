# StandART — Печать (лендинг)

Одностраничный сайт производственной компании StandART: **широкоформатная, интерьерная и УФ-печать**.
Один экран без прокрутки на десктопе (три карточки услуг), на телефоне — обычная вертикальная вёрстка.

## Файлы

- `index.html` — вся страница (разметка + стили страницы + логика)
- `design-system.css` — **общая дизайн-система для всех сайтов**: палитра, шрифт, кнопки, базовые правила
- `assets/logo_standart.webp` — логотип (прозрачный фон), `.png` — запасной вариант
- `assets/favicon.png` — иконка вкладки
- `assets/og.png` — превью ссылки в мессенджерах (1200×630)

## Как поменять контакты

Открыть `index.html`, найти в самом низу в `<script>` блок:

```js
const CONTACT = {
  phoneText: "+7 926 731-53-99",     // как показывать на странице
  phone:     "+79267315399",         // для ссылки tel:
  whatsapp:  "79267315399",          // номер для wa.me (без +)
  telegram:  "Zabatyrb",             // Telegram для консультаций (без @)
  channel:   "standart_decor",       // Telegram-канал
  instagram: "stand_artproduction"   // Instagram
};
```

Править **только здесь** — телефон, WhatsApp и Telegram подставятся по всему сайту
(шапка, нижняя полоса, модальное окно расчёта).

## Как сделать следующий сайт в том же стиле

1. Скопировать `design-system.css` в новый проект.
2. Подключить: `<link rel="stylesheet" href="design-system.css">`.
3. Свою тему (другой оттенок фона, другой акцент) задавать **только** в `:root` после подключения:
   ```css
   :root{ --bg:#0b0b0c; --panel:#141416; --red:#e3261c; }
   ```
   Бренд-палитру (`--walnut`, `--cream`, `--apple`, `--ember`) не переопределять — иначе сайты
   перестанут выглядеть как одна компания.
